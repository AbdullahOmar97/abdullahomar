# Educational Lesson Generator Rule

When the user asks to explain recently completed tasks as a lesson or tutorial in Arabic:
1. Deliver the explanation in clear, natural, human Arabic (فصحى سليمة).
2. Teach foundational engineering principles ("First Principles") to elevate beginners to an expert mindset.
3. Include an English-Arabic technical glossary explaining all domain terms.
4. Provide step-by-step code breakdowns, before-and-after comparisons, senior-level best practices, common pitfalls, and practical exercises.
